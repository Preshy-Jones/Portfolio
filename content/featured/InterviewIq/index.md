An AI-powered interview preparation core backend platform built with Java, Spring Boot, and PostgreSQL. I engineered robust APIs to process mock interview responses, coordinating external integrations via background jobs, including transcription via AssemblyAI and analysis by Claude AI using the STAR method. I built a comprehensive backend system handling JWT authentication, progress tracking schemas, and the complete interview state machine. I also integrated a geo-aware payment reconciliation system — Paystack for Nigerian users and Paddle for global users — with secure webhook processing and a credit-based access model, demonstrating a deep understanding of idempotency and failure recovery.
