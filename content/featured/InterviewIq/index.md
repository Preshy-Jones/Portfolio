An AI-powered interview preparation platform built with NestJS and PostgreSQL on the backend and Next.js with Tailwind CSS on the frontend, with a
  companion React Native mobile app. Users record mock interview responses which are transcribed via AssemblyAI and analyzed by Claude AI using the STAR  
  method framework to deliver structured, actionable feedback. I built a full authentication system with JWT, a progress tracking dashboard, a question
  library with category filtering, and a complete interview session flow from recording through to AI feedback. I also integrated a geo-aware payment
  system — Paystack for Nigerian users and Paddle subscriptions for global users — with webhook signature verification and a credit-based access model.
