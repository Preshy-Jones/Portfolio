An AI-powered interview preparation platform built with Python (FastAPI), React, and Next.js. I engineered a Python backend that orchestrates real-time calls to the OpenAI API to evaluate and score mock interview responses, delivering intelligent feedback to users. I built a comprehensive system architecture handling JWT authentication, secure database schemas, progress tracking dashboards, and the complete interview logic engine. I also integrated a geo-aware payment API using Paystack for Nigerian users and Paddle for global users on the backend.
