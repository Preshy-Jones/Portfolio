A high-performance URL shortener API built with Java and Spring Boot. I developed a
scalable REST API to validate input URLs and generate unique short codes, utilizing Redis for fast lookups. When
the short code is accessed, it reliably redirects users to the original URL. The system is designed to handle a high volume of requests efficiently with careful database design and background jobs for analytics.
